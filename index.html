How this is calculated

For an object at distance u, a lens of focal length f focused at distance s with aperture N (f-number) produces a blur spot (circle of confusion) on the sensor of diameter: 

c(u) = f² · |u − s| / (N · u · (s − f))

This is a thin-lens result and depends only on the lens and focus settings — sensor size doesn't change the physical blur spot. Sensor size does determine what counts as "acceptably sharp": the dashed line for each row is the conventional acceptable circle of confusion, sensor diagonal / 1500. Where a solid curve dips below its dashed line, that part of the scene reads as in focus — the width of that region is the depth of field.

Sensor size also sets the horizontal field of view for a given focal length: FOV = 2·atan(sensor width / (2f)). A smaller sensor "crops" the same lens to a narrower FOV, which is why a 50mm lens looks more telephoto on Micro Four Thirds than on full frame.

The "35mm equivalent" column applies that same crop factor (full-frame diagonal / sensor diagonal) to both focal length and aperture, giving the full-frame settings that would frame the same shot with a comparable depth of field — the usual way of comparing gear across formats.

By default the graph plots raw blur diameter on the sensor itself, which depends only on the actual (non-equivalent) focal length, aperture, and distance — a smaller sensor's lens can produce a physically smaller blur spot even when its equivalent aperture is "faster." The Normalize blur to full-frame equivalent option (in the graph's display settings) multiplies every curve and threshold by its row's crop factor, matching what you'd actually see comparing final images enlarged to the same output size — this is what makes the graph agree with the 35mm-equivalent column.
